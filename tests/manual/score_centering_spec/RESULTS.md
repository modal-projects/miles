# DFlash2 score-centering validation: 2026-10-03

The inference checks establish correct captured probabilities and score-centering
arithmetic for the tested Qwen3.8-27B/DFlash2 configuration. They do **not** establish
numerical equivalence between model execution paths or training-quality parity.
The paired training audit is still in progress.

Implementation: [Miles draft #11](https://github.com/modal-projects/miles/pull/11).
Dependency: [SGLang draft #69](https://github.com/modal-projects/sglang/pull/69).
See [README.md](README.md) for launch commands, pinned models/image, and the
meaning of each check. The SGLang base is normal `sglang-miles` at
`2b7313dc21a57251f568553247d36d78e585a614`; the tested dependency head is
`79f36a8a1b49f84d8ade21b8f9a4cae0db6d6b4d`. `stitch-sglang-v0.5.20` is only a
patch reference. No Miles Dockerfile change points at that branch.

## Correctness

The one-H200 inference matrix used BF16, FA3, float32 Mamba state, block size 8,
explicit `top_k_first`, and exact stochastic acceptance. Twelve settings cover
unfiltered capture K32/K128, sampling top-k32, and top-k64/top-p0.9, each at
temperature 0.7, 1.0, and 1.3. Filtered capture width is 128. The 84-request matrix
was supplemented by two longer requests to obtain full-logit gradient snapshots
for settings whose bounded snapshot quota had been consumed by trimmed rows.

| Check | Observed result | Acceptance criterion |
| --- | --- | --- |
| Generated tokens | 1,720 across 86 requests | No aborted responses; valid production metadata |
| Retained post-prefill verifier rows | 1,634/1,634 aligned | Every retained row; exact token/prefix alignment |
| Row roles | 1,383 accepted drafts; 165 rejection bonuses; 86 all-accepted bonuses | All three roles exercised |
| Emitted logprob versus verifier | Maximum absolute error `4.40049e-6` | `2e-5` |
| Verifier versus independent float64 filtering reference | Maximum probability L1 error `1.85018e-6` | `2e-5` |
| Dense-surrogate gradient comparison | 90 checks; 30 each for none/TIS/MIS; all 12 settings | Absolute `1e-7`, relative L2 `1e-5` |
| Gradient error | Maximum absolute `9.31894e-14`; relative L2 `1.59164e-8` | Both gates passed |
| Native/OpenAI endpoints and production assembly | 12/12 direct and 12/12 router cases | K32/K128, complete filtered support, natural EOS and string stops |
| Final CUDA suite | 29 passed in 28.70 seconds | Both target-only and DFlash2 rejection paths |

The first token is generated by ordinary prefill and is outside the speculative
trace. Another 453 committed rows beyond response termination were counted and
excluded explicitly. The actual DFlash2 model uses the chain/rejection verifier;
synthetic tests also exercise the distinct target-only verifier. Model-independent
kernel law tests do not establish that every draft method supplies correct inputs.

Two defects were corrected without loosening gates: sparse filtering discarded
top-k cutoff ties, and top-p renormalization could prune a row with `p=1` when
float32 input mass rounded above one. The final dependency preserves ties and
disabled top-p rows. Top-k32 with capture width32 produced support overflow in
19/21 negative-control requests because ties expanded support to 33–35 tokens.
The final width128 cases retain full support rather than truncate or renormalize
only a captured subset.

The actual router is the image's unchanged `sglang-router 0.3.2`, with the same
binary in inference and training. This result does not cover separately rebuilt
newer gateway code.

## Numerical controls

These comparisons replay the **same prefixes**, not merely the same random seed.
Recorded-token L1 omits the uncaptured tail in unfiltered cases; filtered L1
covers the complete support.

| Comparison | Result |
| --- | --- |
| Patched regular versus unmodified pinned base, both `joint` | 18 prefixes, 36 cold/warm comparisons; maximum recorded probability L1 `6.04e-8`, logprob difference `2.38e-7`; zero support differences |
| Spec generation versus regular prefill, 312 prefixes replayed twice | Maximum L1 `0.0993` for unfiltered recorded candidates; `0.1050` for filtered full support |
| Regular generation versus regular prefill control, 312 prefixes | Maximum L1 `0.0811` |
| Cold/warm cache diagnostic, 16 worst prefixes from each source | Spec-source cold/warm maximum L1 `0.0955`; regular-source maximum `0.0811` |

The dependency-only control agrees closely under the same filtering order.
It covers temperature 1, unfiltered K128, and top-k64/top-p0.9; it is not a
comparison across every matrix setting.
The larger decode/prefill/cache differences remain material and unexplained.
Their presence in ordinary controls does not show they are harmless, diagnose a
cache bug, or establish spec/non-spec equivalence. Exact-verifier correctness and
model-forward equivalence are separate claims.

## Throughput

Trace instrumentation was disabled. Each trial used eight concurrent requests
of exactly 256 tokens, three repeats, temperature 1, and a full 256-token warmup.
The timer includes HTTP transport and JSON decoding; it excludes artifact writes
and validation. Entries are median tokens/second with observed min–max ranges.

| Capture setting | Regular | DFlash2 | Median ratio |
| --- | --- | --- | --- |
| Unfiltered K32 | 481.4 [250.2–481.6] | 1,099.1 [1,027.1–1,140.2] | 2.28x |
| Unfiltered K128 | 462.1 [454.4–463.0] | 1,015.4 [895.2–1,061.9] | 2.20x |
| Top-k64/top-p0.9, support width128 | 476.0 [475.9–477.3] | 911.1 [894.3–942.2] | 1.91x |

Capture-disabled medians were respectively 490.5/1,154.2, 489.2/965.0, and
489.5/1,020.5 tokens/second (regular/DFlash2). DFlash acceptance and verification
work varied between stochastic trials; K128's capture-enabled median exceeding
its disabled median is not evidence that capture improves performance. Unexplained
first-trial outliers remain in the ranges and raw results. These short measurements support
the observed speed ratios, not a precise general capture-overhead estimate.

## Training integration

Pending: four matched three-step arms, regular/DFlash2 crossed with
unfiltered/top-k64-top-p0.9 sampling. All use the same converted checkpoint,
dataset, optimizer settings, and text-only objective. The audit requires mixed
reward groups, nonzero active advantages and gradients, finite score-centering
metrics, changed language-model weights, two post-update synchronizations, and
valid subsequent rollouts. DFlash private tensor hashes must remain unchanged;
the target's shared draft `lm_head` is recorded separately.

The earlier run using an incompatible response-format scorer produced zero
rewards and zero gradients and is retained as an **inconclusive negative control**.
It is not counted as successful training. The corrected scorer's 32-response
preflight produced 19 correct responses and three mixed-reward prompt groups.
The vision encoder is unused in this text-only recipe; excluding it from weight
equality checks does not establish its preservation across memory offload.

## Evidence and limits

The inference source audit matched all 2,865 uploaded Miles files to
`aaf7fa7362d8cca9b997b1087fa3107bd7701949` and all 4,105 SGLang Python runtime
files to the tested dependency commit above. The full-warmup benchmark was added
later at Miles `5a6a18f3c3`; its executed file SHA256 is
`c2b1ab6f36844a93a5b962044b23a6a05e9c3c7303a52c459c34eed3618ca3cb`.
Installed package Git labels alone are not used as source provenance.

The complete inference archive contains 526 hashed artifacts plus
`ARTIFACTS-MANIFEST.json` (527 files; 218,463,540 bytes), including
raw responses, verifier snapshots, failed controls, all timing trials, exact
launch/source manifests, and diagnostics. It is preserved locally as
`/tmp/score-centering-experiments/score-centering-inference-artifacts.tar.gz`
and in the `score-centering-spec-results` Modal volume, environment `jason-dev`,
at `/score-centering-inference-artifacts.tar.gz`. All member hashes were verified.

Archive SHA256:
`f17a3c4545c5ffd4e9779956f7f2ed8bcff2f2f8750a147f12ecf4d543f5a3c8`.

The bundle includes the run-specific `cold_warm_replay.py`,
`dependency_control.py`, `probe_top_p_identity.py`, and `start_server.py`
diagnostics alongside their inputs and launch manifests. The reusable matrix,
gradient, endpoint, replay, benchmark, and training probes are committed in this
directory. The inference bundle does not substantiate the separate training
claims.

This is DFLASH integration evidence for the pinned Qwen/DFlash2 configuration.
It does not establish long-run RL stability, training-quality equivalence,
multimodal support, or compatibility with every model, draft, or router build.
